启动不久的短空闲仍记录到CPU活动，不能解释为长期稳定空闲；没有小时级泄漏或长期资源结论。107的30秒原生350MiB及108的48小图60轮离屏/GC记录保留并按原范围引用；本轮输入尺寸、宿主、堆上限及采样路径不同，不把数值差别称为性能回退或提速。
