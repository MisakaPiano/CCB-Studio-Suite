## 原因与实现

- 原折叠控件依赖异步偏好读取，且任意c.busy操作期间直接不渲染；因此保存/导入尚未结束时整组消失。改为常驻并从已有LibraryState解码；未就绪/损坏时不覆盖记录。折叠保存一次原子更新内解码已有状态，不重复load整个管理库。
- 排序支持添加时间、自然文件名、文件大小、文件类型和升降序；根默认与各相册配置分开保存，进入相册后选择“本相册默认排序”即记住此相册。来源目录身份使用收集入口/相对父目录或已记录源父路径；提示词相册身份引用固定权威的比较key，不改Prompt、Recipe或分组算法。持久身份散列，不另写明文Prompt/路径。图库生成记录核验投影按不可变资产ID/SHA与完整生成任务快照缓存，重复切页复用；资产或任务改变后失效，首次核验和失败反馈仍保留。
- APNG把返回/模式/当前封面/说明收在顶部，说明按需展开；“添加”“当前结果”“整批处理”分类菜单，来源对照可隐藏。64dp横向缩略图配10dp可见滚动条，换图自动滚到选中，新追加默认最后一张。大图悬浮翻页、左右键、点击大图下一张及缩略图选择同一批次。
- 工具可空批进入，本页添加图片、目录本层、粘贴或拖入；只将明确传入且已成功入库的图片追加输入，输出不偷偷回流。目录不注册为自动收集入口、不递归，最多1000张/批，最多检查10000个目录项；沿用原件导入与逐项回执，取消可保留已提交原件。
- 图片区域及缩略图右键使用专门结果菜单；没有“复制原图”。复制为处理文件列表，保留APNG字节，不提供imageFlavor栅格回退。单张另存、图库副本使用已完成结果的来源/模式/封面/世代快照；换图/预览未完成/失败不允许复制保存。旧菜单世代不同则拒绝操作；批量导出继续使用固定编解码器并生成独立完成目录。
- 保留原件、旧配置及独立多套封面管理。仍拒绝动态WebP静默静态化，伪装不是加密/隐私清除。全局单写入及关闭前取消/排水保持。
