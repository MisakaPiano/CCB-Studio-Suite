# Preview 109 — 批量生图工作台与启动更新提示

用户批准按第一版完整工作台实施，入口沿真实创作页的“连续生成”区域扩展，后续简化入口概念不替代完整工作台。起点44e89329fdf8db4c913506dd642800fe629e9a7d，分支feature/windows-rc-continuous；Prompt对比继续PENDING。真实服务、私人图片与凭据未用于本轮测试。

## 实现范围

- 单次、连续和批量入口保留在生成设置内；当前参数入队不会立即发送请求。工作台支持独立可缩放窗口、分组、Ctrl/Shift多选、勾选开关、拖动排序/边缘滚动、底部磁贴和可调预览栏，采用已确认的深色样式。
- 当前创作、Prompt资产、图片已验证历史/原有元数据读取器及空白分组可入队。每组冻结Prompt、模型、角色、尺寸、次数和Seed；每个请求仅一张，默认横/纵/方各4次，先生成Seed再发送。已开始分组不可覆盖或移除，可复制为新组。
- 单请求串行；默认每次间隔60–80秒，每运行60分钟休息5–7分钟。随机时点采样一次并持久化，重开不重新抽取缩短等待；睡眠唤醒不追赶连发。可调节最短间隔与额外随机量。
- 每次请求前检查账户和权威估价；默认Anlas上限0，仅免费，预计扣费则暂停。未知尝试的预计消耗仍计入预算。不与手动生图/图像后处理并发。
- 429包括额度请求错误均整批暂停，保留Retry-After，禁止跳过绕行或新建批次绕过；倒计时结束仍须手动确认，重开/更新绝不自动续跑。其他错误也暂停。取消与不确定结果不会自动重发；已收到并保存的结果不重复请求。
- 每张原件与请求来源入库，批次/分组/尺寸/轮次/Seed关联留存。完整请求回执存不可变资产并验证散列，热状态文件只存引用，避免长Prompt重复令工作区日志超限；旧内联回执兼容。
- 启动每进程自动检查一次签名更新源；发现更新提示查看或稍后，稍后关闭弹窗但保留顶部待办标记，离线保留已知提示，确认已是最新后清除。不会自动下载/安装，不打断正在运行的批次。

## 验证与限制

只使用合成图片、隔离工作区、回环HTTP替代服务和虚拟时间。自动化不等于真人验收，真实NAI结算、429服务端实况和数小时真实批次未调用/未测。

初轮5项状态检查通过；14项集成断言通过但测试期间源码改变，sourceStable=false，不能作发行通过。稳定36项回归中35通过、1项旧测试仍定位已改名的“全不选”而失败；已按现有“清空选择”语义纠正，后续回归据实追加。真实Compose渲染发现对话框深色文字对比问题已修复，并增加可见滚动条。

30组×12张=360请求的虚拟时间调度覆盖随机间隔、休息和完成；不是真实服务跑图。实际生产生成链通过回环服务核对429停批、无隐式重试、恢复和来源重开；补充额度请求期间暂停、已保存图片后流错误等边界。

首版限文生图；图生图/inpaint/参考引导必须显式移除，避免隐式更改参数。退出/更新暂停批次，恢复需用户确认。归档留存原件与来源，归档浏览管理可后续完善。最终源码、冻结回归、安装器和公开签名更新结果在完成后追加；当前文档不表示109已发布。
