## 实现范围

- 单次、连续和批量入口保留在生成设置内；当前参数入队不会立即发送请求。工作台支持独立可缩放窗口、分组、Ctrl/Shift多选、勾选开关、拖动排序/边缘滚动、底部磁贴和可调预览栏，采用已确认的深色样式。
- 当前创作、Prompt资产、图片已验证历史/原有元数据读取器及空白分组可入队。每组冻结Prompt、模型、角色、尺寸、次数和Seed；每个请求仅一张，默认横/纵/方各4次，先生成Seed再发送。已开始分组不可覆盖或移除，可复制为新组。
- 单请求串行；默认每次间隔60–80秒，每运行60分钟休息5–7分钟。随机时点采样一次并持久化，重开不重新抽取缩短等待；睡眠唤醒不追赶连发。可调节最短间隔与额外随机量。
- 每次请求前检查账户和权威估价；默认Anlas上限0，仅免费，预计扣费则暂停。未知尝试的预计消耗仍计入预算。不与手动生图/图像后处理并发。
- 429包括额度请求错误均整批暂停，保留Retry-After，禁止跳过绕行或新建批次绕过；倒计时结束仍须手动确认，重开/更新绝不自动续跑。其他错误也暂停。取消与不确定结果不会自动重发；已收到并保存的结果不重复请求。
- 每张原件与请求来源入库，批次/分组/尺寸/轮次/Seed关联留存。完整请求回执存不可变资产并验证散列，热状态文件只存引用，避免长Prompt重复令工作区日志超限；旧内联回执兼容。
- 启动每进程自动检查一次签名更新源；发现更新提示查看或稍后，稍后关闭弹窗但保留顶部待办标记，离线保留已知提示，确认已是最新后清除。不会自动下载/安装，不打断正在运行的批次。
