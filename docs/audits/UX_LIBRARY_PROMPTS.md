## 当前实现

`LibraryRepository` 在既有 AssetStore 中追加不可变管理版本，保存别名、多标签、多个目录入口、来源观察和参照位置；不改 A1/R1 核心，不建立另一套原件数据库。外部目录仅显式选择后只读扫描，原文件更改生成新资产，缺失/读取失败保留原件。默认收集目录通过明确入口启用，位于独立数据根旁。Prompt 是独立资产，修改生成新版本；图片和管理内部记录按类型分离。图库查询支持别名/标签。

图片预览直接读取已保存历史或沿用 Desktop PNG 参数读取器。关联历史请求损坏时明确失败，不回退为空数据或用当前草稿代替。来源为图片的 Prompt 快照保存原件 ID/SHA、各段及角色、Recipe 和参数投影；同一原件同一内容重复加入不会不断生成重复快照。

多来源参照支持图片/独立 Prompt 混用；图片在上，各字段成行对齐，空白 Prompt 不参与比较。拖动角色标题或上移/下移只改变参照位置，保留原角色索引/位置，原 Prompt 字节、Recipe、请求和创作草稿不变。差异按原文分段精确显示，未改权重或官方请求。常用参数默认显示，完整字段可展开；未知参数不补默认值。窄窗口横向滚动。

摘取进入可编辑草稿，保留来源资产和段 ID，可复制/保存独立资产；用户确认后才应用创作，操作本身不调用 AI。完整 Recipe 与请求快照分别查看/复制；已有请求摘要验证失败就阻止读取。历史无摘要明确单列状态。AI 设计会话已由原创作模块保存，但旧图没有设计关联字段时只标“未记录”，不按时间猜测关系。
