## 发现与修复

- 用户反馈下载缺少实际进度，完成提示不明显。增加真实下载字节、总量、百分比、速度，独立校验状态；校验、落盘及提交完成后才展示醒目的下载完成卡片与安装按钮。安装仍需主动确认。
- 更新成功后再次检查，旧客户端把相同版本报告为 FAILED。原始回执与截图保留。新客户端仅在可信目标与安装版本、来源 SHA、资料格式一致时返回 UP_TO_DATE；低版本、未知身份、同版本不同身份/格式仍拒绝。实际安装器的严格“必须更新”检查不放宽。
- 修正后的客户端以当前 B 安装配置重新访问同一可信演练源，实际返回 UP_TO_DATE；独立缓存，无下载/安装。结果保存为 `actual-current-check.json`。这不是安装了新 UI 的声明。
- 用户反馈最小化、最大化、关闭大小不一致。现有工作台使用字体字符，已改为直接适配 Desktop 的 Canvas 图形：统一 12 dp 画布、1 dp 线宽、居中、还原图标及悬停/按压反馈。两个 Suite 顶栏使用同一按钮组件。
- 导航采用 Desktop 的 17 dp 图标+13 sp 文字、36 dp 高标签和选中背景；窄窗保留 36 dp 图标入口及提示，窗口控制为 42/46 dp。Suite 有七个入口，因此文字切换阈值调整到 860 dp；宽窗品牌文字在 1100 dp 以上显示。保留蓝色 CCB logo。
