## 修复与行为

上一检查点实际查看小人书截图发现中文方框。测量、换行及缺字检查使用了回退字体，绘制却使用原字体；导出共用渲染器也受影响。现逐行绘制使用与测量相同的字体，页码同样处理；导入字体的基线修正仅用于实际采用该字体的行。以 Arial 中英混排与实际可显示的 SimSun 输出比较，修复前图片散列不同、测试 FAILED，修复后相同。源 TypeSet 换行/布局合同未简化，之前的失败图片保留。

预览检查真正缺失的字体和无法显示的 Unicode 字形，并明确报错；切换原图仍可查看，原始字节不变。不把不可读预览视作导出成功。

导出显示已生成/总页数；打包、资产保存、发布和结果验证分别展示阶段，最终完成仅在输出校验通过后出现。停止不发布未完成批次、保留已有临时成果；重试需明确操作。完成目录可打开或复制路径；剪贴板失败不会抹去已经校验的文件成功状态。

确定性测试在第 1/3 页暂停线程。第一轮发现进度触发重绘时，界面读取持有长操作锁的 workspace.state，界面被阻塞直到 20 秒故障栅栏超时。现界面使用控制器已缓存的状态，并合并当前编辑工程最新名称；不放松数据单写/排水门禁。测试实际点击停止、确认未发布完成标记、显式重试完成，再模拟复制失败，文件均保留。进度回调不在原子发布之后抛异常。
