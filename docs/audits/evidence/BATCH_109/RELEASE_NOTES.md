# 0.0.0-preview.109 — 批量生图与更新提醒

创作页“生成设置”中的连续生成区域新增“批量任务”：把当前参数加入队列，再进入完整工作台开始。保留单次和连续生成。

- 支持多组参数、横/纵/方次数、Ctrl/Shift多选、拖动排序、独立窗口和结果预览；每次请求1张，逐张入库。
- 默认随机间隔60–80秒，运行60分钟后随机休息5–7分钟，可调整。每次请求前检查预计费用，默认仅免费；已有参数和请求来源保留。
- **429整批暂停，冷却结束仍需手动确认恢复**。其他错误、退出、更新也不会自动续跑；已保存结果不重复发送。
- 每次启动自动检查可信更新，发现新版可选择查看或稍后；稍后会在顶部“更新”保留待办提示。下载和安装仍由用户确认。

实验Preview。批次首版限文生图，不支持带图像引导入队；真实NAI长时间批次和本版原生日常重启尚未人工验收。自动检查使用合成资料/回环服务，无真实生图调用。Prompt对比继续暂缓。

现有用户通过应用“更新”下载、保存后安装并重启，无需重新填写已保存账户。首次升级到109仍需手动检查；109之后启动自动检查生效。
