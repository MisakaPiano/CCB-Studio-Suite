# Preview119 — 编辑改善、工程管理与内置本地识别

实验性 Windows x64 邀请 Preview；尚非稳定版或全项目验收。

- 编辑界面保持三栏，整理队列、工具、属性与图层；沿既有 TypeSet 参考完善竖排、预设、快捷键、批量及多种导出。切换页面保留工程，连续编辑沿用工具设置。
- 工程栏合并重复入口：收起保存后可从本机列表重开，归档与本机列表分开；名称与多层组织可一起管理。归档不重复复制原图或工程，不自动清除编辑历史。废弃须确认，原图、共享内容及已有备份保留。
- 新完整包导入只保存原图及 Studio 支持的当前可编辑内容，不额外保留整份包、外来历史与未知字段；外部包及已有导入资料不清理。主动导出完整工程包可交给另一台 Studio 继续编辑，包含原图和当前内容；不包含本机撤销历史、字体文件、模型或凭据。单包仍限64MiB。
- AI本地识别模型内置，首次无需寻找文件；默认一键识别并跟随当前打码工具，可在设置中改用自选模型或独立效果。工作区／工程不重复复制内置权重。当前为检测框打码，并非像素分割或智能擦除；识别准确率需用户检查。
- 编辑预览及共用图片浏览宿主使用独立窗口，支持真正最大化、还原、关闭隔离及跟随主题标题栏。
