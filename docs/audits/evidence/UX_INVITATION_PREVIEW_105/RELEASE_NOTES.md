# CCB Studio Suite — 0.0.0-preview.105

首个以生图与图库管理为核心的邀请实验版，Windows x86_64。包含内置运行环境，无需另装 Java。

本轮包含：NAI 账户与单一生图模型设置、动态预计消耗、可独立打开的 AI 设计窗口；图库目录/标签相册、搜索与标签联想、批量标签、常用排序、Ctrl/Shift/框选、拖入用途磁贴、可调预览、可逆回收站；APNG 静止封面、多套封面库与结果文件操作。24 图导入性能和进度反馈已修复，持续性能优化另行跟进。

用户已确认 AI 设计→应用→实际生图，且重开后图片和 Prompt/模型/生成参数保留；图库交互与标签/回收站、磁贴/拖动/目录导入/选中显示分别通过限定人工验收。最终 57 项合成桌面回归实际通过，涵盖原件保留、导出与恢复拒绝覆盖；不代表全部功能或服务商人工验收。

## 安装与持续更新

下载安装程序，选择新的空程序目录；不覆盖旧测试目录。程序与资料分开，默认资料位于 %LOCALAPPDATA%/CCBStudioSuite/workspace-v3，旧 workspace-v2 会沿用并按已有安全迁移流程处理。安装器不删除旧工作区，不自动搜集外部目录。

此前快捷方式指定了独立测试工作区时，新安装不会擅自搬运它。原窗口正常保存关闭后，可继续使用相同 --studio-root 和 --runtime-root 启动新程序，或在应用备份与恢复中恢复到新目录；不要同时打开同一工作区，不在聊天里发送凭据。旧资料保留。

在应用“更新”页检查、下载并应用后续 Preview；更新验证签名、版本与文件散列，安装到新的版本目录，保存排水后重启，保留资料和旧程序，并生成 Launch-CCB-Studio.lnk 指向已验证新版本。后续源码推送并不等于新二进制已发布，只有发布到此渠道的版本才会被应用发现。已装长期渠道 102/103 者先经 104 桥接；100/101 临时链安装请使用本次新安装，不替换旧信任根。

## 已知问题与实验范围

- 多来源 Prompt 新工作台设计暂缓，既有参照功能保留；完整比较人工专项未签收。
- 编辑/排版/批量交付及编辑产物恢复有自动回归，连贯人工检查后置；当前 APNG 快捷键文件接收端也未补测。这些附加功能持续改进，不作为本次核心验收结论。
- 原大目录收集仍未签收重扫/全量完整性，建议先小目录、保留原件。文件导入/目录同步会在资产库保留原件，外部目录只读；不是仅保存路径引用。
- APNG 伪装不是加密，主动播放仍可显示内容；不同接收软件对动画支持不同。
- 标签分类、原始 tag 映射和修改时间排序未提供；广泛性能/资源专项后续推进。
- 文本接口为 HTTPS OpenAI 兼容协议；模型出现在列表不代表支持识图，不宣称完整 Desktop 模型管理或原生 Claude/Gemini 协议。
- 预计消耗不是服务端最终扣费保证。结果不确定时不要盲目重复付费提交。
- 备份不包含可直接复用的凭据，恢复到独立目录后需重新配置凭据和外部收集入口。跨机器恢复尚未人工验证。
- 无 Windows Authenticode 发布者签名；TUF 更新签名不是 Windows 代码签名。现有自动续签已实际运行，仍需离线维护 root/targets。
