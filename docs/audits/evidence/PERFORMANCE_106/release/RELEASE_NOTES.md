# CCB Studio Suite — 0.0.0-preview.106

图库缩略图性能与资源优化更新，Windows x86_64 邀请实验版。

- 图库卡片、回收站列表和资产选择窗口使用静态缩略图；动画在大图中查看，小卡片不再逐张持续播放。
- 队列与图库共用每工作区8 MiB解码像素缓存，最多2个解码任务。同一张图的并发请求合并，离开最后一张卡片即取消未完成读取，更新/关闭前等待任务退出并清空缓存。
- 24张1536×2048合成PNG的解码/缓存对照：旧冷1.35–1.71秒，新冷0.25–0.27秒；保留像素72 MiB降到4.5 MiB；暖缓存十次访问没有额外读取。仅代表此合成解码场景，不代表整个程序速度或常驻内存。

52项受影响自动回归实际通过，覆盖图库交互、目录/标签/排序、APNG封面、取消排水、回收站/备份、更新与凭据快照。原图字节、导出复制和大图播放保持原有路径，未改动锁定的Desktop权威实现。没有使用私人资料或新增真实AI/生图调用。

在现有105应用的“更新”页检查、下载、安装并重启。沿用原签名更新渠道、独立资料目录和本机加密凭据；保留旧程序。也可下载安装器到新的空程序目录，不能覆盖旧程序或资料目录。

本版保持Preview实验范围；多来源Prompt新工作台设计继续PENDING。首次邀请105已披露的附加编辑/排版连贯人工、标签分类/tag映射、原大目录重扫和多服务商兼容性等限制仍然适用。本轮没有人工电脑操作验收；整机RSS/空闲CPU及真实大图库测量仍待后续。缓存预算不包括可见卡片引用和解码器的临时原尺寸缓冲；特别是WebP后备解码的临时峰值仍需继续优化。

不包含Windows Authenticode发布者签名；内置TUF更新签名沿用既有信任根。APNG伪装仍不是加密，主动播放可显示内容。
