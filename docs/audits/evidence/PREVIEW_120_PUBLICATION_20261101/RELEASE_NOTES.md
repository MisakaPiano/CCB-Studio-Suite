# Preview120 — 减少重复目录扫描、明确打码范围与页面说明

实验性 Windows x64 Preview，承接119；不是全产品或真实千图性能验收。

- 目录没有变化时，周期补查比较文件条目和属性，不再每分钟重读全部图片并计算完整散列。启动、文件变更事件、监听溢出/失效或发现属性变化仍走完整扫描；手动同步和实际入库校验保持。属性稳定不等于内容完整性认证。
- 编辑工具栏直接提供“自动打码·当前图”和“自动打码·所选N张”。所选指编辑队列勾选的图片，每次最多100张；点击后固定处理范围，结果显示实际处理数量，仍可撤销，原图不覆盖。
- 图库“移入回收站”放到下方操作磁贴栏，保留确认和恢复；右侧回收站入口用于查看、恢复。标签/日期高级筛选默认收起，已有筛选显示摘要，收起不清空筛选。
- 主页面右上角提供圆形“?”帮助按钮，与主题按钮拉开间距；按当前页面显示简短使用说明，可关闭并重开，不强制弹出。
- 承接候选已固定的局部预览/来源查询与分组提交改进、目录导入边界、蓝色图标及NovelAI参数兼容修正。参数采用固定来源，未知/不支持内容明确拒绝，不把局部通过扩为全模型/全参数/API验收。
- 纳入已限定复核的更新中断恢复与程序修复工具：新可信安装包可在独立同级目录修复同版本程序，保留原损坏程序和入口备份；资料与运行时不迁移，不强杀占用。资料或定位描述自身损坏不属于程序修复能力。

已限定人工通过：帮助按钮区分与间距、图库默认呈现/操作可发现性、编辑打码范围文字和布局。合成自动检查分别覆盖局部正确性、原件字节保全和66秒空闲补查（无新增内容扫描、文件变化仍正常同步）；不是千图、长期资源或各页全面性能结论。原生自动截图失败与历史测试失败/UNKNOWN保留。

**尚未解决的存储问题**：图库单份原件＋目录/相册引用的改造尚未实施，已有目录副本也未清理；本版不声称消除了本地重复保存。需要减少后台收集时，可在资产管理→目录入口暂停自动收集，保留已入库资料，之后手动同步。未来清理须先核对归属、字节一致性及引用依赖，不动源文件和现有资料。

真实千图体验、长期CPU/RSS、其他原待办与Prompt对比保持原状态。未自动更新日常安装，没有新增真实生图调用。保留原TUF信任根；Windows Authenticode发布者签名仍未提供。
