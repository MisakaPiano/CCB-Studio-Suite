## 实现

- 缩放预览复用显示解码得到的方向修正后尺寸，每次图片展示只读取一次；去掉独立尺寸探测的第二次完整读取。
- 静态图的格式检查结束后立即释放 Skia 数据/解码器，再进行显示解码，减少同时持有的资源。
- 显示图不再重新编码 PNG 然后再次解码。按整行读取 ARGB 并转换为一次 RGBA 栅格传递，避免通用逐像素转换产生大量临时对象。显示尺寸限制、方向和透明度保留。
- 临时静态解码/缩放画布及 APNG 帧/合成画布在 finally 中释放；不增加全局大图缓存，不在生产代码强制 GC。
- 换图重建图片展示状态；慢图、失败图和被取消任务不继续展示上一张。取消检查在静态转换前后执行；已有动画循环取消保持。
