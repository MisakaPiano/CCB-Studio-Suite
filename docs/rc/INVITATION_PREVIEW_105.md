## 已验证范围与已知限制

- 图库/标签/回收站以及磁贴、跟手拖动、目录导入、普通选择与勾选显示有各自限定人工回执。
- 词库更新、账户/模型保存、NAI 真实生成、AI 独立窗口和动态预计消耗有各自限定回执；预计消耗不等于服务端最终扣费保证。
- 图片目录收集会将原件保存在资产库；外部目录不被修改。原大目录继续暂停，未签收其重扫/全量完整性；邀请测试优先小目录。
- 新多来源 Prompt 对比布局暂缓，现有参照功能保留；完整多来源人工专项尚未签收。
- 编辑/排版/批量交付及编辑产物恢复有自动回归，连贯人工检查未完成；当前 APNG 快捷键处理文件接收端也未补测，均为实验附加功能。
- 修改时间排序尚不支持；现有排序为添加时间、名称、大小和类型。标签分类和原始 tag 映射未实装。
- APNG 是静止封面/主动播放内容的格式处理，不是加密；接收程序的动画支持不同。处理文件复制未就绪时不得退回原图。
- 模型列表不代表每个模型都支持识图。当前文本服务为 HTTPS OpenAI 兼容接口，不宣称完整 Desktop 配置或原生 Claude/Gemini 协议支持。
- 本机独立目录恢复已验证，跨机器恢复仍未验证。应用资料备份不包含可直接使用的账户凭据；恢复后需重新配置凭据及显式启用外部目录入口。
- 没有 Windows Authenticode 发布者签名；更新元数据的 TUF 签名不等于 Windows 代码签名。既有自然定时续签现有一次 schedule 成功证据，仍需持续维护离线 targets/root。
