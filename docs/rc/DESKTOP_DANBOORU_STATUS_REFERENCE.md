## 追加：紧凑伪装页与安全结果操作

用户新反馈是伪装页纵向按钮/说明/封面占用过多，应将返回、模式、当前封面及说明收在紧凑工具栏，按添加/当前结果/整批处理分类；直接接文件、目录本层、拖入/粘贴，悬浮/左右键/点击翻页及可见缩略图滚动条。Suite本轮实现见[专项记录](../audits/UX_GALLERY_SORT_COMPACT_APNG.md)，新增原生操作尚未人工签收，不推断Desktop当前版本已实现或没有实现。

特别需要独立评审复制安全：来源对照和缩略图的右键也不应偷偷复用“复制原图”。只提供“复制当前处理文件”，使用已完成且匹配来源/模式/封面/世代的结果字节，APNG复制走文件列表、无栅格回退；预览未完成/失败、换图后旧菜单均不能回退到来源。另存/保存副本同样固定结果身份，不把输出自动追加输入批次。目录导入须限制范围、可取消，不借机注册持续扫描用户目录。

图库方面，Suite原控件在偏好读取前及任意busy期间消失，现改常驻并复用已加载管理快照；排序分添加时间/自然文件名/大小/类型、升降序，根与每相册分别保存。Desktop若采用须按自身存储/分组身份接线；不重写权威Prompt比较算法，不以同层或同名目录代替单相册身份。此段是新增方案，原固定Desktop观察不被自动刷新。

## 已确认的显示缺口

`app/desktopApp/src/main/kotlin/com/example/chatbar/desktop/DesktopNovelAiStudioController.kt` 的 `checkCatalog()` 会写入 `catalogUpdate` 和状态：“词库已是最新版本”或“词库更新已就绪，下载 N 字节”。

`DesktopNovelAiStudioPanel.kt` 的“设置”辅助窗口只放检查/下载按钮与两个开关，没有渲染上述检查状态。主 Studio 在另一处显示 `state.status`，设置窗口挡住主窗口时用户不能在操作位置辨认检查结果。因此“点击没反应”不能判断为最新版，也不能据此确认网络检查成功。

## 建议行为

1. 在检查按钮附近常驻独立词库状态：尚未检查 → 正在检查 → 已是最新 / 发现更新 / 检查失败。进入检查时立即显示反馈；失败不能归入“已是最新”。可附最后检查时间和本地版本标识，便于区分旧消息。
2. 只有发现更新才显示下载按钮；开始下载后防重复提交。分别显示下载、校验、构建索引、整理和更新完成，未知总量时使用不确定进度，不编造百分比。
3. 索引构建可显示真实计数。Suite 当前在 SQLite 适配层回报已收录词条数及已处理索引记录数；没有改共享索引排名、编码或 Prompt 请求算法。大词库构建耗时不等同失败。
4. 下载与检查由独立词库任务管理，允许“返回 Studio（后台继续）”。主窗口保留简短状态和词库自己的取消按钮；关闭设置不取消任务，不占用生成/设计的任务锁。退出整个程序则取消并等待资源释放，不承诺应用关闭后继续。
5. 在校验和索引完成前不替换有效词库；先落不可变数据和索引，最后原子切换活动清单。失败/取消保留旧可用词库，切换已完成时如实说明，避免用“取消”暗示回滚。
6. 成功切换后刷新补全和中文注释服务，移除下载候选；再检查应显示最新。校验失败、断网及取消均有可见终态，并允许显式重试。

## 验证重点

- 已最新、有更新、断网/异常三种检查结果在设置窗口可见，不能只看下载按钮是否出现。
- 慢速下载/索引时返回主窗口仍可编辑，再开设置能看到同一任务；重复点击不会创建第二任务。
- 取消、关闭应用和失败保留旧词库；切换和重新检查、注释刷新验证单列。
- 自动测试用合成数据库和截获 HTTP；真实词库及原生窗口验收分开记录。不要把编译或状态字符串存在认定为用户已看到。

## 图片查看器右键与直达入口（用户明确要求转交）

同一只读观察中，Desktop `DesktopViewerPresentation.kt` 已有鼠标悬浮左右翻页，`DesktopImageViewer.kt` 大图窗口已接入，并保留底部翻页和方向键。大图底部“图像工具”打开 `DesktopImageToolsDialog`，其中有 APNG 伪装/还原。聊天图片另有 `ContextMenuArea`，内容为“编辑并重新生成”（有参数且可生成时）及“删除这张图片”；**大图查看器的图片区域没有接通用右键菜单**。“编辑并重新生成”指修改生成参数，不能等同 Suite 的 TypeSet 图片编辑工程。

建议在 Desktop 大图图片区域接右键菜单，复用原有复制、保存及图像工具能力，提供适当的伪装/还原和可用编辑入口。应与现有底部按钮使用同一组回调；不能把聊天消息专用删除/重生成操作无条件搬到所有本地图片。没有生成参数时不提供假复现；工具不支持的动画保留原件并明确说明。

Suite 本轮新增“复制图片、另存原始文件、进入编辑、APNG 伪装、APNG 还原”，右键与底部按钮共享操作，另补悬浮翻页。操作针对查看器当前页，不依赖图库旧选择；进入编辑建立单图独立工程并先保存原工程，动画沿用已有首帧编辑确认；进入 APNG 只打开工具，不自动处理/导出。原件不覆盖。Suite 自动回归及人工状态见本轮记录，不替代 Desktop 自己的验证。

验证需要真实右键能打开菜单、翻页后操作对象正确、忙碌时写入操作不可用、旧编辑工程和原件保留；悬浮按钮不挡滚轮缩放/拖动，首末页不越界。复制/保存与原有格式规则一致。用户同时要求此差距在邀请版前补齐，不能因为工具在其他页面存在就签收查看器完整。

## 自定义 APNG 伪装封面与默认封面预览

用户随后明确要求：处理结果默认显示伪装封面，播放内容单独控制；可保存多套自定义封面，并能恢复 CCB 默认封面。只读核对的 Desktop `DesktopImageTools.disguise(source)` 没有封面参数，内部 `cover(width,height)` 固定背景和品牌Logo；`DesktopImageToolsDialog` 直接调用它，未发现多套封面配置、选择及恢复默认入口。因此此项在本次观察中是明确缺口，不能用APNG编解码器能写默认图代替产品功能已经实现。

Suite 改法供独立审查：保留共享 `ApngDisguiseCodec` 原字节，在桌面适配器给 disguise 增可选封面原件；按目标画布等比适应并补深色边，通过原 Writer.writeDefaultImage 写入，内容动画帧/心跳/时序不改。未选自定义时走原CCB默认封面路径。配置有名字、不可变资产ID/SHA及当前选择，单独保存在工作区管理版本中；可多套切换、重命名、移除配置、恢复默认，恢复默认不删除自定义封面。备份恢复随工作区保留，不写入凭据或外部目录权限。

预览默认关闭动画，每次新处理/换图/换封面重置到静止；明确区分“伪装后的封面预览”与主动“播放原内容”。静止预览读PNG默认IDAT图，不能从动画播放画面猜封面。用户截图里播放开关开启，不能据该图断言旧静态解码一定错误。预览、副本和批量导出使用同一封面选择；切换后清除旧预览，导出回执写入封面ID/SHA，避免展示一套、导出另一套。

验证应包含两套不同颜色合成封面、重开/备份恢复、恢复默认不清空配置、损坏配置拒绝静默重置、静止封面像素与内容播放不同、GIF多帧/循环/时长保持，以及复制/导出实际接收端。Suite的实际自动结果与人工待测仍单独记录；没有修改Desktop，更不把Suite测试视为Desktop已通过。

## 自动预览与批次缩略图

用户进一步要求免去每次点击预览，增加横向缩略图滚动条并默认定位最新。Suite现按当前处理批次快照实现：进入选最后一项，图片/模式/封面变化后自动延迟120ms预览；独立可取消任务不占生成/设计锁，过时结果按递增身份拒绝展示。关闭工具取消；退出/更新前取消并等待所有当前及被替代的工作释放资源。自动操作只产内存预览，不自动保存副本、导出或调用服务，失败有明确状态及显式重新预览，不盲目循环重试。

纯预览应先在短暂只读操作内取不可变输入快照，再做内存变换；不要借用限制单个创建/写入任务的工作区门槛。Suite的故障注入测试确实发现过“旧预览未退出导致新预览被拒绝”的错误，已按此分离修正并单列复验；不能仅把UI的busy换名而留下底层锁冲突。关闭任务集合要覆盖已取消但尚未结束的旧工作，排程与维护关闭之间要防止漏收。

缩略图沿用现有StudioFilmstrip选择/横向滚动/自动滚到选中逻辑。顺序来自用户当前批次；选择与大图、封面预览同步，不把新输出偷偷追加回输入队列反复伪装。此为Suite批次工作台扩展，不推断Desktop单图工具已具有同样批次管理；Desktop接入时需按自己的单图/批次所有权独立设计。
