## 规模与现有基础

按每组Prompt、横/纵/方各4次、每次1张计算：20–30组共240–360张。若发起间隔60秒且单张不超过60秒，基础耗时约4–6小时，再加休息、慢请求和人工处理时间。次数与单次出图数量分开；不把4次自动改成一次请求4张。

源码观察f321972：StudioApplication.generate已有单组连续循环，StudioGenerator已有生成参数快照、请求证据、逐张入库和结果来源；关闭自动限流重试，已提交结果保留。StudioWorkspace把中断任务标为UNCERTAIN。可复用这些路径，禁止另写Prompt拼装/请求协议。

现有连续生成不是可恢复批次队列：缺少组/方向/轮次标识、节奏、休息、持久化待办、错误待确认和队列UI；同时绑定WorkbenchController全局busy，不能直接把循环延长数小时。错误当前被折叠为通用安全说明，需补充不含token/Prompt/响应正文的结构化阶段、HTTP/服务错误码和关联ID。

## 建议第一版行为

1. 创建明确有上限的批次，冻结每组正负Prompt、角色、模型、Steps/CFG、三种尺寸、次数与seed策略。任务中途修改创作草稿不影响已排队内容。默认每次1张、串行；应用内手动生图与批次共用同账户发送锁，防止并发。
2. 默认发起间隔60秒，可调；下一次同时满足“上次发起已过间隔”和“上一请求已结束、结果已落盘”。慢请求不重叠，休眠唤醒不补发积压。建议运行60分钟休息5分钟，参数可调，界面同时显示下一次和下一休息倒计时。此为用户节奏选项，不是全应用统一限速。
3. 默认按组完成横/纵/方各4次；可选轮询各组，优先让每组先有一套结果。独立随机seed为默认；对比用途可选每组三种尺寸共用4个预先保存的seed。横纵方必须选具体分辨率，不仅交换宽高。
4. 所有错误立即暂停整个批次，显示失败位置、阶段、错误码/简明原因与已保存结果；绝不到时自动重试。操作为“重试当前”“跳过当前并继续”“结束批次”，明确一次恢复指令。限流仍尊重服务端最早可重试时间；倒计时结束不会自动解除错误暂停。
5. 超时、断网、中途取消或进程退出可能发生在请求已提交之后，单列“结果未确认”；不把它视为确定未生成，不自动补跑。重试可能重新计费，由用户明确决定。结果文件落盘与任务完成以可恢复记录衔接，重启核对已入库结果，防止已成功项再跑。
6. 普通暂停为“完成当前张后暂停”；保留立即中止选项，说明本地中止不代表服务端撤销。退出/更新时先暂停排水，重开只恢复记录、等待手动启动。首版应用保持运行；无需开系统常驻服务，不做关闭应用后继续生图。
7. 开始前显示总张数、预计时长、各尺寸预计消耗；默认不允许自动从免费/体力转为Anlas扣费。用户可设Anlas上限；无法确认额度或余额不足则暂停。运行时以最新已知额度和实际响应更新，不把初始估算当结算。额度查询失败同样待确认，避免盲跑。
8. 结果逐张进入图库，保留批次/组/方向/轮次/seed及原生成来源。批次页能直接筛出本批结果；未完队列仅保存描述和资产引用，不持有数百张原图。缩略图沿用有界缓存；计时在后台协程完成，持久化只在状态变化时写，不按秒重写整个库。

## UI入口和布局

主入口放创作页生成按钮旁的真正浮层菜单：“立即生成 / 加入批次 / 批次任务”。运行时创作页显示紧凑状态入口，例如“批次·85/240·等待32秒”，点击回到工作台；暂停/停止属于批次工作台，不恢复全局右下停止。

批次工作台作为创作里的子页面，可切出独立可缩放窗口；不增加顶层导航标签。顶部一行放批次名、账户、进度与开始/暂停；左侧可滚动组列表（组名、尺寸、4×3、完成/错误）；右侧可调宽度的当前结果预览；底部一条节奏/休息/额度设置，低频选项放设置浮层。每组可展开横纵方进度，整页不铺240张完整任务卡。详情、日志和错误说明按需展开。

添加来源先接现有创作参数快照、已保存Prompt资产、图库图片的“参数与来源”；以后AI设计结果也能直接“加入批次”，无需覆盖当前草稿。批次只是参数快照集合，不启动仍PENDING的多来源Prompt对比/摘取工作台。首版建议文生图；图生图、局部重绘及复杂参考映射需另验，不能把横纵方切换当作自动正确裁切。

## 服务侧边界

2026-10-23核对[NAI图像API](https://image.novelai.net/docs/doc.json)：生成说明要求由人发起，禁止通过自动生成制造过量负载。文档未提供“每60秒一次即被允许”的保证，因此不能把休息计划宣称为官方许可或规避限流；长时无人值守适用范围需进一步核对。技术上可先完成有限批次的参数/队列/暂停设计及纯合成调度验证，不以此判定服务侧授权。

[NAI FAQ](https://docs.novelai.net/en/faq/#opus-usage-limits)说明V5 Opus体力逐步恢复，并非整点或短休息重置；尺寸、步数等影响消耗。节奏休息与额度不足暂停必须独立，不能保证240–360张均免费。
