### 来源与保存方式核对

- `LibraryRepository.addFolder`只保存目录入口；`LibraryWorkspace.addFolder`只注册/刷新。自动收集开启时，后台监视器之后可能同步；不能承诺启用自动收集后一直只有路径登记。
- `LibraryRepository.scan`调用`StudioWorkspace.importImage`，后者将原始字节写入`AssetStore`并校验。因此同步/收集是只读外部目录、在Suite库内保留原件，并非纯外部文件引用。已记录且未变化的文件走UNCHANGED；同目录同来源关系不因每次同步重建资产。这里不承诺跨目录相同内容在界面上全局去重。
- 普通显式导入/粘贴还有`retainIngressBatch`写专用imports目录的次级副本；外部目录收集不调用这一步。保留资产库原件与额外imports副本要分开解释，不能把所有来源统一称“导入副本”。
- 拟按来源显示目录收集、文件导入、生成结果、处理结果；详情单独显示保存方式。此细分尚未生产实现，不通过改文案悄悄改存储模型。若另需不入库的纯引用模式，须独立设计外部丢失、变更、编辑导出及备份行为。

|相册整卡单击|进入相册；角标、封面、名称遵循同一规则，不打开封面大图。Ctrl/Shift 或勾选模式下优先选择，不跳转|
|图片单击 / 双击|单击设置当前项并选择、右侧预览；双击打开该项大图。队列双击打开当前处理结果，不能意外导出/生成|
|Ctrl+单击|切换该项是否选中，其余选择保留；点击已选项不把整个集合变成单项|
|Shift+单击|按当前可见顺序从锚点连选；Ctrl+Shift 添加范围。过滤/排序/离开相册时处理旧锚点，不能按旧数组下标误选|
|空白处拖动|显示框选范围；默认替换选择，Shift 合并，Ctrl 切换范围。超过边缘的持续拖动需受控自动滚动，不启动后台文件扫描|
|勾选模式|默认关闭；开启后显示复选框，点击选择不导航。关闭只隐藏复选框，不清空选择，也不禁用 Ctrl/Shift 和框选|
|右键已选项 / 未选项|已选项保留整组选中；未选项先单选该项。菜单标签区分当前与所选数量；空白右键只提供添加/视图等操作|
|拖动已选项|超过拖动阈值才开始，整组高亮并显示数量；拖未选项先选择该项。松到无效目标/按 Esc 取消，原选择不丢失；拖动不误触发单击/双击|
|键盘|方向键移动当前/焦点，Shift 扩选，Ctrl+A 选择当前可见范围，Space 切换，Enter 打开，Esc 取消菜单/拖动；文本输入获得焦点时不抢快捷键|
|返回路径|后退/前进与上一级独立；恢复相册自己的排序、滚动位置和可用焦点。不因进入相册覆盖创作草稿|

## 拖动到用途的边界

- 图库到编辑：按当前可见顺序固定选中资产列表，建立/追加工程前明确目标；保留原件、当前未保存工程及撤销边界。
- 图库到多 Prompt 参照：主动加入有 Prompt 的选中来源，不先覆盖创作。无 Prompt 或混合来源显示可加入/不可加入数量及原因；这不代替独立多来源比较专项。
- 图库到 APNG：把固定选中列表加入工具队列，不能因拖动自动生成全部处理结果、导出或删除图库原件。
- 工具队列内移除：只移除输入队列；不显示会让人误以为删除原件的泛用“删除文件”。不把拖到其他用途按钮解释为移动原文件。
- APNG 复制/导出/拖出：只提供与 source/mode/cover 身份一致的处理文件；未就绪时禁用并说明，不以原图回退。预览显示原内容或来源对照不改变这一边界。外拖可能触发文件准备，必须有独立任务/取消/资源排水，不能持整个工作区锁阻塞前台。
- 混合相册和单图选择展开时按稳定 ID 去重；目标受理固定快照，不使用随后变化的当前项。外部拖入与内部用途拖动分开识别，不冒充系统文件剪贴板完成。
