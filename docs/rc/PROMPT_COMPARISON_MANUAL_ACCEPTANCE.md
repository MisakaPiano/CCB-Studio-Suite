# 多来源 Prompt 对比：独立人工验收

用户于2026-10-23明确把此能力列为重点，要求之后单独验证。本文件是待办，不表示已通过，也不在当前交付时发起这组人工操作。使用合成或用户自行选择的资料；私人 Prompt、图片和 Key 不发送到聊天或公开证据。

## 进入比较的三类来源

|来源|主动入口|期望|
|---|---|---|
|AI 设计结果|每轮候选下“候选加入多 Prompt 参照”|直接保存候选原文和角色、会话/轮次来源；不先应用当前创作，不把当前画风混入候选；重复点击不重复创建同一快照|
|复制或导入的图片|图库图片预览“图片加入多 Prompt 参照”；多选后“图片工具 → 所选图片多 Prompt 参照”|读取图片已有参数或保存的生成记录；没有可读 Prompt 明确告知，不能拿当前草稿代替；派生图片注明来源图片|
|独立文字|资产管理 → Prompt 资产 → 粘贴文字/导入文件/新建 → “保存并加入多 Prompt 参照”|不依赖图片，不经过当前创作区域；保留输入原文。已有资产可用“加入多 Prompt 参照”|

## 验收顺序

1. 在创作中先保留一段容易辨认的草稿和未发送 AI 输入。分别通过三类入口加入，核对草稿、未发送输入和当前模型/账户未改变；加入本身不联网、不生图。
2. 混合至少三来源，核对风格、基础、负向、角色非空字段按行展示；空白不伪造成内容。标点、换行、权重及角色负向保持原文。AI 候选的目标模型不冒称实际生成参数，未记录的 Seed/采样信息显示未知。
3. 两来源角色顺序相反时拖动或上移/下移对齐，只改变参照位置。返回创作和原图片参数，原角色/请求顺序不得改变。
4. 检查仅看差异、窄窗横向滚动、长文滚动与复制。图片原件、Recipe、请求快照和派生来源分别辨认；损坏历史不能假装读取成功。
5. 摘取多个字段到独立摘取区，编辑/复制/保存；取消应用后当前创作不变，确认应用才更新且可撤销。所有比较/摘取动作均不自动发送 AI。
6. 关闭重开后，比较来源、原文、角色展示顺序仍在；合成工作区备份/恢复到新目录后再次核对。原图片字节保留，重复加入同一图片/同轮候选不不断生成重复快照。

AI 设计实际生成、图片导入以及多来源比较可分别签收；一次生图成功不能替代整组验收。每步记 PASS/FAIL/NOT TESTED，遇错保留现有资料，不为了通过重新生成或覆盖原件。
