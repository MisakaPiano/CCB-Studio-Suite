# 多来源 Prompt 对比：实施前的工作台设计

2026-10-23 JST；观察源码 `aeafb6668c38fbf4b7e5ae6f1ec4c55393428d13`，图库四项人工回执已在 `403d9b0` 推送。用户要求后续Prompt先设计、确认后实施；本轮仅概念，不替换生产页面、不构建新应用包。

## 保留的范围

既有 `PromptReferenceBoard.kt` / 核心 `PromptReferences` 支持图片/候选/独立文字参照、最多16来源、非空字段按行对齐、只看差异、角色展示次序、参数/Recipe/请求/设计关联、摘取与明确确认应用。当前板嵌在资产管理的滚动列中，摘取区在矩阵之后；本设计整理空间和入口，不能省略已有功能。

三种来源保持直接入口：AI候选原轮次快照、图片已有Prompt/生成参数、独立粘贴/导入文字。加入比较不覆盖当前创作、未发送AI文字或账户/模型，也不自动调用AI/生图。无可读非空Prompt的图片告知原因；独立无结构文字只显示原文，不猜测其画风/角色字段。

## 两种可操作布局

- **底部摘取（建议）**：顶部常驻来源管理与Prompt/参数切换；比较矩阵占整个宽度，摘取区停在下方独立区域。适合3–16来源，矩阵内部横向查看，摘取不必滚到整页末尾。
- **右侧摘取**：同一矩阵与操作，右侧常驻摘取。两来源时摘取方便，三来源以上更容易需要横向滚动；窄窗自动转为下方。

矩阵的来源标题/预览与字段列在其滚动区中固定。来源不必有图片：候选/文字用明确类型占位，不显示虚构生成图。每字段可完整原文查看/复制，按字段摘取或先选择部分原文；长内容滚动。相同字段按同一行对齐，不按文本高度错位。

角色标题在同一来源列中可拖动，也提供上/下移按钮。原始角色标识与参照位置分别显示；原资产、Recipe和最终请求顺序不改，不能借“自动对齐”猜人物身份。

摘取保持准确来源、可编辑/复制/保存为独立Prompt；预览应用展示前后影响，取消不改草稿，确认后才经现有权威解析/应用路径执行且可撤销。不增加新的Prompt解析器或请求语义。概念仅使用一个基础文本字段演示应用，不能视为复杂角色应用已经实现或通过。

参数未知就写未记录；AI目标模型不冒充实际生图模型。保存的Recipe、实际发送请求和AI设计关联各自判断，不按文本/时间相似度造关联。概念的合成图无已验证请求，点“实际请求快照”显示未记录，不生成虚假快照。
